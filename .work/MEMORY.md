# Crystallized Memory & Heuristics

## Heuristics & Rules
- **Date**: 2026-08-31
- **Project**: 3D Portfolio for English Teacher (Mr. Ahmed Samir).
- **Rule 1 (GSAP vs CSS Conflicts)**: Never use Tailwind `transition-all` or `transition-transform` on elements animated by GSAP. Use property-specific transitions (e.g. `transition-colors`) to avoid frame-by-frame interpolation wars and snapping.
- **Rule 2 (GSAP Sub-Pixel Shift)**: Always set `force3D: true` on GSAP `.to()` and `.fromTo()` tweens for images/cards to prevent sub-pixel matrix drop shifts upon tween completion.
- **Rule 3 (Mobile URL Bar Jitter)**: On mobile browsers, ignore `window.resize` events where only height changes (< 140px) due to address bar collapse. Always set `ScrollTrigger.config({ ignoreMobileResize: true })`.
- **Rule 4 (Fast Scroll Completion)**: Never set `fastScrollEnd: true` if you want animations to reliably play when scrolled to quickly.
- **Rule 5 (Adaptive WebGL Scaling)**: Detect CPU cores and RAM via `navigator.hardwareConcurrency` & `navigator.deviceMemory`, and install a dynamic FPS watchdog to self-heal performance on low-tier mobile devices.
- **Rule 6 (Full-Page Fixed WebGL Canvas)**: If a WebGL canvas is fixed in the viewport as a global ambient background (`fixed inset-0`), do NOT bind `IntersectionObserver` to a single section like `#hero`. Pause rendering ONLY via `document.addEventListener('visibilitychange')` when the tab is hidden to prevent freezing background animation on scroll.
- **Rule 7 (Exploratory Font Selection & User Approval Gate)**: When the user asks to see/explore options ("وريني", "شوف حاجة"), NEVER apply changes directly to the production codebase until the user explicitly reviews the visual options in chat/studio and chooses the exact preset by name.
- **Rule 8 (Cinematic Background Depth of Field)**: To eliminate visual clutter and separate 3D floating background objects from foreground UI text and portrait photography without dragging GPU frame rates, apply a subtle CSS blur (`filter: blur(1.8px)`) with slight hardware-accelerated scaling (`transform: scale(1.015) translateZ(0)`) to the background canvas. This creates photographic bokeh, prevents edge clipping, and lets the foreground pop with crystal clarity.
- **Rule 9 (Timeline vs Bento Grid for Short Data)**: `2026-09-01 | Timeline Slop | Root Cause: Forced a vertical timeline format onto a very short (3 items) and highly asymmetrical data set (26+ years vs 2 diplomas), creating awkward empty spaces and repetitive "AI Slop" labels. | Forbidden Path: Standard vertical timelines for < 4 unbalanced items. | Permanent Rule: Use Asymmetric Bento Grids for 3-item asymmetrical data lists. Highlight the core value proposition (e.g. 26+ years) in a large 2/3 spanning card, and stack the minor supporting details in smaller 1/3 cards. This naturally breaks visual monotony and feels premium.`
