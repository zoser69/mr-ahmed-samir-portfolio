# Crystallized Memory & Heuristics

## Heuristics & Rules
- **Date**: 2026-08-31
- **Project**: 3D Portfolio for English Teacher (Mr. Ahmed Samir).
- **Rule 1 (GSAP vs CSS Conflicts)**: Never use Tailwind `transition-all` or `transition-transform` on elements animated by GSAP. Use property-specific transitions (e.g. `transition-colors`) to avoid frame-by-frame interpolation wars and snapping.
- **Rule 2 (GSAP Sub-Pixel Shift)**: Always set `force3D: true` on GSAP `.to()` and `.fromTo()` tweens for images/cards to prevent sub-pixel matrix drop shifts upon tween completion.
- **Rule 3 (Mobile URL Bar Jitter)**: On mobile browsers, ignore `window.resize` events where only height changes (< 140px) due to address bar collapse. Always set `ScrollTrigger.config({ ignoreMobileResize: true })`.
- **Rule 4 (Fast Scroll Completion)**: Never set `fastScrollEnd: true` if you want animations to reliably play when scrolled to quickly.
- **Rule 5 (Adaptive WebGL Scaling)**: Detect CPU cores and RAM via `navigator.hardwareConcurrency` & `navigator.deviceMemory`, and install a dynamic FPS watchdog to self-heal performance on low-tier mobile devices.
- **Rule 6 (Full-Page Fixed WebGL Canvas)**: If a WebGL canvas is fixed in the viewport as a global ambient background (`fixed inset-0`), do NOT bind `IntersectionObserver` to a single section like `#hero`. Pause rendering ONLY via `document.addEventListener('visibilitychange')` when the tab is hidden to prevent freezing background animation on scroll.
- **Rule 7 (Exploratory Font Selection & User Approval Gate)**: When the user asks to see/explore options ("وريني", "شوف حاجة"), NEVER apply changes directly to the production codebase until the user explicitly reviews the visual options in chat/studio and chooses the exact preset by name.
- **Rule 8 (Cinematic Background Depth of Field)**: To eliminate visual clutter and separate 3D floating background objects from foreground UI text and portrait photography without dragging GPU frame rates, apply a subtle CSS blur (`filter: blur(1.8px)`) with slight hardware-accelerated scaling (`transform: scale(1.015) translateZ(0)`) to the background canvas. This creates photographic bokeh, prevents edge clipping, and lets the foreground pop with crystal clarity.
- **Rule 9 (Timeline vs Bento Grid for Short Data)**: `2026-09-01 | Timeline Slop | Root Cause: Forced a vertical timeline format onto a very short (3 items) and highly asymmetrical data set (26+ years vs 2 diplomas), creating awkward empty spaces and repetitive "AI Slop" labels. | Forbidden Path: Standard vertical timelines for < 4 unbalanced items. | Permanent Rule: Use Asymmetric Bento Grids for 3-item asymmetrical data lists. Highlight the core value proposition (e.g. 26+ years) in a large 2/3 spanning card, and stack the minor supporting details in smaller 1/3 cards. This naturally breaks visual monotony and feels premium.`
- **Rule 10 (Default Subagent)**: The official default subagent model to use for all general-purpose tasks is 'flash' (mapping to Gemini 3.8 Flash Medium). Always use this model unless the task specifically requires 'pro' or 'flash_lite'.
- **Rule 11 (WebGL Background Transparency & Zero-Flash Curtain Architecture)**:
  - `2026-09-02 | WebGL Canvas White Flash on Reload | Root Cause: Using opaque WebGL canvas (alpha: false) with scene.background in Three.js, combined with CSS filter: blur() on the <canvas> element. In Chromium/Direct3D ANGLE, an opaque canvas creates an opaque swapchain initialized with white (0xFFFFFFFF) before the first frame, while CSS blur on canvas forces Skia 2D convolution that glitches to white and gets inverted by mobile browser Force Dark Mode. | Forbidden Path: Setting alpha: false on background 3D canvases, applying CSS blur() directly to canvas elements, and relying on CSS opacity hacks instead of a render-blocking curtain. | Permanent Rule: In professional 3D background architecture (Awwwards standard): 1. Set alpha: true on WebGLRenderer and renderer.setClearColor(0x000000, 0) with scene.background = null so the canvas is 100% transparent and CSS owns the background (#060402). 2. Deploy an instant zero-frame dark curtain (#site-curtain) at z-index: 999999 right inside <body> that renders at 0ms. 3. Dissolve the curtain smoothly via onReady callback only after the first valid WebGL frame is rendered. 4. Never apply CSS blur or transform filters directly to WebGL canvas elements.`

## RESOLUTION (2026-09-03) — White Background Root Cause Found & Fixed
- **Root cause**: `renderer.clear()` ran BEFORE `setSize()` + `setPixelRatio()` in `initThreeScene`. Both reallocate the WebGL drawing buffer, so the only clear hit a discarded 300×150 buffer and the final full-size buffer stayed **uninitialized** until the first rAF render. On Windows D3D/ANGLE, fresh GPU memory is intermittently opaque white (`0xFFFFFFFF`) → "sometimes white, sometimes not". `renderer.clear()` now runs AFTER sizing.
- **Amplifiers removed**: `powerPreference: 'high-performance'` (hybrid-GPU present failures composite uninitialized swapchain memory) and header `backdrop-blur-md` (Chromium backdrop-filter snapshot white) → solid `bg-[#060402]/95`.
- **Guarantee added**: `#three-canvas-container` starts `opacity: 0` (critical CSS) and is revealed only after 3 verified rendered frames (1.2s safety); container has solid `#060402` DOM backing; context-loss restore path no longer calls `forceContextLoss()` (killed listener-churn loop via generation tokens).
- **Verified**: 15/15 headless + 12/12 real-GPU visible-Edge reloads (mixed hard reloads), 0 exceptions, pixel analysis shows only cream typography (~1.2%), never a white background. Tools: `.work/cdp-diagnose.mjs`, `.work/reload-test.mjs`, `.work/gpu-reload-test.mjs`, `.work/ghpages-sim.mjs`.
- **Testing gotcha**: `vite preview` ignores `base` routing here — asset URLs (`/mr-ahmed-samir-portfolio/assets/*`) silently fall back to `index.html` (text/html) so the page black-screens with a stuck curtain. Use `.work/ghpages-sim.mjs` (port 4180) for production-parity checks.

- **Rule 12 (WebGL Buffer Lifecycle)**: `2026-09-03 | Intermittent white canvas on Windows D3D/ANGLE | Root Cause: Calling `renderer.clear()` before `setSize()`/`setPixelRatio()` clears only a discarded buffer — the final full-size drawing buffer stays uninitialized (intermittently opaque white garbage) until the first render tick. | Permanent Rule: Always clear AFTER the final `setSize`/`setPixelRatio`; avoid `powerPreference: 'high-performance'` on background canvases (hybrid-GPU present failures); never let a WebGL canvas be the page's only dark layer — gate it at `opacity: 0` and reveal only after several verified rendered frames over a solid DOM backing; never call `forceContextLoss()` inside a context-restore re-init (synthetic lost events misattributed by fresh listeners cause canvas-hiding churn).
- **Rule 13 (vite preview + base)**: `2026-09-03 | Local production test black-screened with stuck curtain | Root Cause: `vite preview` does not apply `base` routing — it serves `dist/` at `/` while the built HTML references `/mr-ahmed-samir-portfolio/assets/*`, so assets 200-as-text/html (SPA fallback) and modules never execute. | Permanent Rule: For GitHub Pages project sites, verify production builds with a static server that maps the base prefix (see `.work/ghpages-sim.mjs`), never with `vite preview`.
